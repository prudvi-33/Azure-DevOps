**Self Healing Applications:** 
=============================
✦ Kubernetes supports self-healing applications through ReplicaSets and Replication Controllers. <br/>
✦ The replication controller helps in ensuring that a POD is re-created automatically when the application within the POD crashes. <br/>
✦ It helps in ensuring enough replicas of the application are running at all times. <br/>
