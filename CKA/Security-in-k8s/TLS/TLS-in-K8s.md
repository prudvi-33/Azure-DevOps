✦︎ **Server** uses public and private keys to secure connectivity. We call them serving **certificates/Server Certificates.** <br/>
✦︎ We have a **Certificate Authority**. CA has its own set of public and private key pairs that it uses to sign **server certificates.** We will call them root certifcates. <br/>
✦︎ How a server can request a client to verify themselves using **client certifcates.** <br/> <br/>
✅ So three types of certificates: <br/>
1. Server certificates configured on those servers. <br/>
2. Root certificates configured on CA Servers. <br/>
3. Client Certificates configured on clients. <br/> <br/>
